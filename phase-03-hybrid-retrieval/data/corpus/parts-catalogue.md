# Spare Parts Catalogue

*Fictional operator: Atlantic Rail. All data in this corpus is invented for testing.*

Part numbers have a three-letter prefix for the system (BRK brakes, PNT pantograph, DOR doors, HVC air conditioning) followed by four digits. Several part numbers look alike, so always check all four digits before ordering.

## Brakes

- **BRK-4471**: brake pad set for the Aurora class 450. Sold in sets of 4 pads.
- **BRK-4417**: brake pad set for the Class 330. Not compatible with the Aurora.
- **BRK-4710**: brake disc for the Aurora class 450. Replace when the disc thickness is below 102 mm.
- **BRK-7441**: brake caliper seal kit, used on both fleets.

## Pantograph

- **PNT-0932**: pantograph carbon strip for the Aurora class 450.
- **PNT-0923**: pantograph carbon strip for the Class 330.
- **PNT-9032**: pantograph damper. It reduces the bouncing of the pantograph at high speed.

## Doors

- **DOR-2170**: door rubber seal. It keeps water and noise out when the door is closed.
- **DOR-2710**: door motor. It opens and closes one passenger door.

## Air conditioning

- **HVC-4120**: HVAC air filter for the Aurora class 450.
- **HVC-4210**: HVAC compressor for the Aurora class 450.
